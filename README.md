# Fable Game Engine!

### she wants to be fabulous when she grows up

This is a project of mine that I've iterated any time Unity Engine maddened me.
As a result it got big fast and eventually I started regularly working on it.

This project is a real game engine project, it's legit. I didn't think it would be
this easy to make one but here we are. This is all thanks to Silk.NET, StbImageSharp,
and StbTrueTypeSharp with respect.

There is nothing stopping you from downloading the engine, opening it in Rider or VisualStudio
or whatever, and trying it out.


If you ever want to try keep in mind that Windows support doesn't exist.
If it doesn't work on your windows machine there is not much I will do. Hope you're
good at programming!
